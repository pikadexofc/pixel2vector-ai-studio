# Visual Reconstruction Plugin Icon Pack

A scalable SVG master plus raster exports for common plugin, app, and web icon sizes.

- `icon.svg`: editable vector master
- `icon-16.png` through `icon-1024.png`: PNG exports at 16, 24, 32, 48, 64, 96, 128, 180, 192, 256, 512, and 1024 px
- `favicon.ico`: multi-resolution favicon
- `manifest.json`: asset inventory and recommended usage

Recommended plugin sizes: 48 px small icon and 128 px large icon. Use 512 px or 1024 px for high-resolution app artwork. Use the SVG master wherever SVG is accepted.
