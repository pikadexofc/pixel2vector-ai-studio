# Design preferences and precedence

## General design preferences

Modern, minimal, high-contrast visuals; clean composition; dark or charcoal themes where suitable; soft white text; selective cyan/chromatic accents; legible typography; restrained cinematic lighting; glassmorphism only when useful; no gratuitous noise, cartoon styling, cyberpunk, graffiti, excessive neon, or heavy texture.

## PixelPie Media brand evolution

Historical palette: Deep Black `#090909`, Charcoal `#1A1A1A`, Soft White `#F5F5F5`, PixelPie Orange `#FF7A1A`, Electric Cyan `#00F5FF`, Neon Magenta `#FF008C`. The current direction de-emphasizes orange and prefers a chromatic family of pink, magenta, cyan, and blue over a dark foundation. Treat the exact color system as project-specific and confirm the current brand file before production.

## PixelPerfect Studio provisional palette

The current package uses a near-black blue-grey base `#0B1117`, soft white `#F5F7F8`, and cyan `#00D4E3` / `#00C8D7`. This is a temporary plugin identity until the supplied final icon/brand art can be incorporated.

## Personal portrait constraint

When a request explicitly creates a portrait or personal-brand image representing the user, preserve the user's stated visual requirement: half-body portrait, face mask, sunglasses, and cinematic lighting. This rule applies only to personal representation, not generic people, client subjects, or unrelated creative work.

## Conditional style system

Editorial Neo-Brutalist Collage v1.1.0 is activated only by an explicit request. Modes: Signal Collage (violet/yellow), Transit Blue Editorial, Quiet Typographic Event. Do not apply by default.

## Precedence

Current explicit project brief > latest confirmed brand decision > relevant stable preference > explicitly selected reusable style system > proposed default.
