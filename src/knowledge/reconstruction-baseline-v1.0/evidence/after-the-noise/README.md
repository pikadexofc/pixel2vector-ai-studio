# After the Noise | PixelPerfect Studio Reconstruction

Canvas: 1536 × 569 px.

## Files
- `index.html`: self-contained composition referencing local source-derived cutouts.
- `preview.png`: Chromium render at native canvas dimensions.
- `analysis.json`: evidence-classified forensic observations.
- `layer-manifest.json`: 14-layer production manifest.
- `qa-report.json`: render and structural checks.
- `assets/`: transparent, source-derived architectural and paper-edge cutouts.

## Run
Open `index.html` in a modern browser. No remote fonts or scripts are required. The headline remains live text.

## Fidelity note
The concrete collage components are masked extracts from the supplied reference, while the black torn field, paper texture, geometry, drafting marks and text are rebuilt as independent layers. This is a first-pass reconstruction, not a pixel-perfect certification.
